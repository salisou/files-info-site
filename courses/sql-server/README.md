# Corso completo di SQL Server

Corso interattivo in italiano per studiare SQL Server e T-SQL, dai fondamenti agli argomenti di amministrazione.

## Avvio

Apri `index.html` in un browser. Non è necessario installare dipendenze.

Per usare il corso senza accesso a Internet, tieni presente che AlaSQL e i font vengono caricati da CDN e richiedono una connessione.

## Struttura

- `index.html` — pagina principale del corso
- `css/styles.css` — stili e layout
- `js/app.js` — navigazione, lezioni ed editor SQL
- `js/course.js` — testi del corso e indicazioni sugli esercizi specifici di SQL Server
- `data/database.js` — dataset locale per gli esercizi

## Editor SQL

L'editor integrato usa AlaSQL per eseguire nel browser le query compatibili su un dataset dimostrativo locale. È un simulatore didattico, non un'istanza di Microsoft SQL Server. Per provare i comandi T-SQL specifici, usa SQL Server Management Studio (SSMS) o Azure Data Studio.
